# HappyTG 0.4.31

HappyTG `0.4.31` reduces recurring Docker healthcheck overhead and ships the verified Mini App Desktop rendering optimization.

## Highlights

- `0.4.31`
- API, worker, bot, and Mini App readiness probes now use `curl -fsS --max-time 4` instead of spawning `node -e`.
- App readiness checks run every `30s` instead of every `10s`.
- The shared app image installs `curl` with `--no-install-recommends` and removes apt metadata after installation.
- Mini App Desktop rendering keeps the opaque no-blur top bar, bounded session list loading, staged load-more controls, and session-card containment.

## Safety Notes

- HTTP `/ready` semantics are preserved; probes still fail on connection errors and non-success responses.
- Docker Desktop control continues through `HAPPYTG_CODEX_DESKTOP_CONTROL=host-proxy`.
- Only `api`, `worker`, `bot`, and `miniapp` were recreated during local runtime verification; stateful dependencies and Caddy were left running.
